# A 3D scene

glonk draws meshes through a perspective camera, lit by lights you choose, in characters or on the pixel canvas. A 3D scene is a camera, meshes placed in the world, and lights.

## A camera, a cube and a light

```go
var sun = []mesh.Light{
	mesh.Ambient{Level: 0.2},
	mesh.Directional{Direction: geometry.Vector3{X: 0.4, Y: -1, Z: 0.6}},
}
```

```go
	cam := mesh.Camera{Position: geometry.Vector3{Y: 1.5, Z: -3.5}}
	cam.LookAt(geometry.Vector3{}) // at the origin

	cube := mesh.Cube(2)
	cube.Transform.Yaw = 0.6 // turned, so that two sides show
	cube.Material.Color = engine.Palette(208)
	cube.DrawShaded(fb, cam, sun...)

	fmt.Println(fb)
	// Output:
	// ┌────────────────────────────┐
	// │                            │
	// │                            │
	// │                            │
	// │         %%%%%%%%%-         │
	// │         ******---          │
	// │         ******---          │
	// │          *****--           │
	// │             **-            │
	// │                            │
	// │                            │
	// └────────────────────────────┘
```

- **The world is in units of your choosing.** +x is to the right, +y up, and the camera looks down +z when it is not turned.
- **`mesh.Camera{}` is a working camera,** at the origin. Its defaults are a field of view of a quarter turn, a near plane 0.1 away, and cells twice as tall as they are wide.
- **`Yaw` and `Pitch` turn the camera,** in radians. `LookAt` sets both, so that it looks from its `Position` at a place. Call it each frame after moving the camera.
- **A mesh is placed by its `Transform`:** `Position`, `Yaw`, `Pitch`, `Roll` and `Scale`. Positive pitch tips its front up, as for the camera.
- **`Material.Color`** is its color, and **`DrawShaded(fb, cam, lights...)`** draws it, lit, in characters: the brighter a cell, the denser its character.
- **Solids hide each other by depth,** whatever the order of drawing, and faces turned away are skipped.
- **A camera with values that make no sense sees nothing,** and a mesh whose `Transform` holds a number that is not finite is not drawn.
- **Cells are taken as twice as tall as they are wide.** Set `Camera.CellAspect` for a font that is not.

## Shapes

`mesh.Cube`, `Box`, `Sphere`, `Cylinder`, `Cone`, `Plane` and `Grid` make meshes without a file. They stand on the y axis, centered on the origin.

- **`Box(w, h, d)`** is any width, height and depth. **`Plane`** is a flat rectangle that faces up, and **`Grid`** lines for a floor.
- **Segments run from 3 to 512, and rings from 2 to 512,** so a careless argument cannot ask for gigabytes.
- **A size that is negative or not finite counts as 0.**
- [Models and textures](models.md) has meshes from files, colors on each vertex, and pictures on faces.

## Smooth shading

```go
	ball := mesh.Sphere(1.3, 24, 12) // radius, segments around, rings from pole to pole
	ball.Transform.Position = geometry.Vector3{X: -1.6}
	ball.DrawShaded(fb, cam, sun...)

	facets := mesh.Sphere(1.3, 8, 5)
	facets.Normals = nil // lit face by face
	facets.Transform.Position = geometry.Vector3{X: 1.6}
	facets.DrawShaded(fb, cam, sun...)

	fmt.Println(fb)
	// Output:
	// ┌──────────────────────────────────────┐
	// │                                      │
	// │                                      │
	// │                                      │
	// │           %%##*+=   %@@@##           │
	// │          ***++=--  *****+++          │
	// │           =------   ------           │
	// │                                      │
	// │                                      │
	// │                                      │
	// └──────────────────────────────────────┘
```

- **A mesh with a normal at each vertex is lit at every cell,** so it looks round. One with no `Normals` is lit face by face.
- **`Box`, `Sphere`, `Cylinder`, `Cone` and `Plane` come with normals,** and so does a model file that has them.
- **`Mesh.SmoothNormals()`** returns a copy with a normal at each vertex, averaged over the faces that share it.
- **It averages shared vertices only.** A cube made of 8 vertices comes out looking like a ball: hard edges need their own vertices.
- **To draw facets,** set a copy's `Normals` to nil.
- **Smooth shading costs about 12 to 23% more** on a scene of spheres. Drawing allocates nothing either way.

## Lights

```go
	floor := mesh.Plane(12, 6)
	lamp := mesh.Point{Position: geometry.Vector3{X: -2.5, Y: 1}, Range: 4}
	floor.DrawShaded(fb, cam, mesh.Ambient{Level: 0.05}, lamp)
	fb.DrawBox(0, 0, fb.Width(), fb.Height(), engine.Color{}) // a frame round the picture

	fmt.Println(fb)
	// Output:
	// ┌──────────────────────────────────────┐
	// │                                      │
	// │        ....:::::.............        │
	// │      .::::--=--::::............      │
	// │    .::::-=+*+=--:::..............    │
	// │  .:::::--===---::::................  │
	// │..:::::::----::::::...................│
	// │..::::::::::::::::....................│
	// └──────────────────────────────────────┘
```

- **`mesh.Ambient`** lights everything a little, and **`mesh.Directional`** from one direction, as the sun does.
- **`mesh.Point`** is a lamp at a place. It fades with distance, to nothing at its `Range`. A `Range` of 0 never fades.
- **A light has a `Color`.** Its zero value is white. In cells the brightest channel picks the character, and a colored light takes a fifth to a third longer to draw.
- **A light of your own** is a type with a `Brightness(point, normal)` method. `mesh.Brightness` adds lights up as drawing does, for things you draw yourself.
- **A lamp is not asked about a mesh wholly beyond its `Range`,** so a level can have a lamp in every room. Your own light opts in with a `Reach` method.

## On the pixel canvas

```go
	canvas := fb.Canvas()
	cube.DrawShadedPixels(canvas, cam, sun...)
	canvas.Compose()
```

- **`DrawShadedPixels`** draws into the [pixel canvas](pixels.md): twice as fine from top to bottom, and shaded by color, not by character.
- **`Compose`** then puts the pixels in the cells. Each cell gets the depth of its nearer pixel, so what is drawn with a depth afterwards is hidden behind nearer pixels.
- **Character shading needs only ASCII,** and the pixel canvas a font with `▀` and `▄`. Nearly every monospace font has them.

## Wireframes and lines on a surface

```go
	floor := mesh.Plane(8, 6)
	floor.Transform.Position = geometry.Vector3{Y: -1}
	grid := mesh.Grid(8, 6)
	grid.Transform.Position = floor.Transform.Position
	cube := mesh.Cube(1.6)
	cube.Transform.Position = geometry.Vector3{X: 0.3, Y: -0.2}
	cube.Transform.Yaw = 0.5

	floor.DrawShaded(fb, cam, mesh.Ambient{Level: 0.1})
	grid.DrawOnSurface(fb, cam, engine.Cell{Character: '+'}) // on the floor, whole at any distance
	cube.DrawShaded(fb, cam, sun...)
	cube.DrawOnSurface(fb, cam, engine.Cell{Character: '#'}) // its edges, on its own faces
	fb.DrawBox(0, 0, fb.Width(), fb.Height(), engine.Color{})

	fmt.Println(fb)
	// Output:
	// ┌────────────────────────────────────────┐
	// │                                        │
	// │                                        │
	// │                                        │
	// │         +++++++++########+++++         │
	// │       +++++++++####%%%%##+++++++       │
	// │     +++++++++++#***####-#+++++++++     │
	// │   +++++++++++++##*****###+++++++++++   │
	// │ ++:::::+::::+::###***###:+::::+:::::++ │
	// │+++++++++++++++++++####+++++++++++++++++│
	// └────────────────────────────────────────┘
```

- **`Draw`** paints a mesh's edges over whatever is there, so a wireframe drawn that way shows through solids.
- **`DrawDepth`** gives each cell of an edge a depth: a nearer surface hides it, and the order of drawing stops mattering.
- **A line that lies on a surface ties with it,** and `DrawDepth` loses some or all of it. **`DrawOnSurface`** draws such lines whole: a grid on a floor, a mesh's edges on its own faces.
- **Draw the surface before its lines.** `DrawOnSurface` reads the surface's slope from what is drawn, and a line more than a quarter of the depth behind is hidden.
- **`DrawPixels`, `DrawDepthPixels` and `DrawOnSurfacePixels`** are the same on the pixel canvas. A line there is one pixel thick.
- **To draw over a scene,** a tool in the player's hand or a model in a menu, `ClearDepth` the canvas or the frame first. It keeps what is drawn.

## Far plane and fog

```go
	cam := mesh.Camera{Position: geometry.Vector3{Y: 1.5}, Far: 30}
	cam.Fog = &mesh.Fog{Color: engine.RGB(40, 40, 60), Start: 4, End: 30}

	for _, depth := range []float64{2, 17, 30} {
		r, g, b := cam.Fog.Apply(engine.RGB(200, 200, 200), depth).RGB()
		fmt.Printf("%2.0f deep: %3d %3d %3d\n", depth, r, g, b)
	}
	// Output:
	// 2 deep: 200 200 200
	// 17 deep: 120 120 130
	// 30 deep:  40  40  60
```

- **`Camera.Far`** is the distance beyond which nothing is drawn. A mesh wholly beyond it is skipped. 0, the default, means no limit.
- **`Camera.Fog`** fades every shaded mesh toward a color by how deep it is: nothing before `Start`, the color itself from `End`.
- **Give `Far` at or after the fog's `End`,** and the world ends in the fog and not in a line.
- **In cells the color fades and the character stays.** Wireframes are not fogged.
- **`Fog.Apply(color, depth)`** fades a thing you draw yourself in step with the meshes.

## Points and rays

```go
	x, y, depth, ok := cam.ProjectPixels(geometry.Vector3{X: 1, Y: 1, Z: 4}, canvas)
	fmt.Printf("in pixel (%.0f, %.0f), %.0f deep, on screen %v\n", math.Floor(x), math.Floor(y), depth, ok)

	origin, dir, _ := cam.RayPixels(20, 12, canvas) // the middle of the canvas
	fmt.Println("the ray starts at", origin, "and goes", dir)
	// Output:
	// in pixel (23, 9), 4 deep, on screen true
	// the ray starts at {0 0 0} and goes {0 0 1}
```

- **`ProjectPixels(p, canvas)`** says which pixel a point of the world is in, and how deep it is. Floor the coordinates to get the pixel.
- **The depth is the distance along the camera's view,** not the straight-line distance: the number `SetDepth`, `Far` and `Fog` use.
- **`RayPixels(x, y, canvas)`** is the way back: the ray through a place on the canvas, for what is under the pointer or the crosshair.
- **The ray's direction is one deep,** not a unit vector, so the point `origin + t*direction` is `t` deep.
- **`RaysPixels(canvas)`** gives every ray of the canvas at once, for a sky or a ray marcher. That is about 14 times faster than asking pixel by pixel.

## Meshes off screen

- **Drawing starts by asking whether any of a mesh can be on screen,** so a scene of many meshes costs little for those out of view.
- **The shapes and models glonk makes know their bounds.** A mesh you build by hand, with its vertices where they are in the world, calls `UpdateBounds` once, and again after a vertex is changed in place.
- **`Validate`** says what is wrong with a mesh: an edge or a face that names a vertex it does not have, normals that cannot be used, bounds that are out of date. What is wrong is skipped when it is drawn.

`go run glonk.dev/examples/viewer@latest` shows models and shapes, solid or as lines, faceted or smooth, under three kinds of light.

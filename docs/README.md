# The glonk manual

Guides to glonk, one for each job, in an order to read them in. Each has code that runs: it is copied from the tests and the examples, which check it.

- [Your first game](first-game.md): install glonk, put a game on screen, and what each part of it does.
- [Keys, text and the mouse](input.md): held keys, shortcuts, typing, a paste and the pointer.
- [Testing a game](testing.md): press keys and read frames with no terminal.
- [Pixels, shapes and pictures](pixels.md): the pixel canvas, shapes, pixel text and pictures.
- [Sprites, collision and tile maps](sprites.md): things that move, walls that stop them, and a level bigger than the screen.
- [Widgets](widgets.md): a label, a panel, a bar, a menu and a text field.
- [A 3D scene](3d.md): a camera, shapes, lights, wireframes, fog and rays.
- [Models and textures](models.md): OBJ files, colors on each vertex, pictures on faces, and see-through faces.
- [Sound](sound.md): sounds at places in a scene, loops and fades, and WAV files.
- [A game in a web page](web.md): the same game as in the terminal, played in a browser.
- [Terminals, colors and limits](terminals.md): what a terminal needs, what glonk uses where it has more, and what glonk does not do.

Every type and function is documented, with examples that run, on [pkg.go.dev](https://pkg.go.dev/glonk.dev). What changed in each release is in the [changelog](../CHANGELOG.md).

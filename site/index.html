Every game starts
with a block.

glonk is a terminal rendering engine for Go. It draws 2D, 3D, or both in the same frame, using plain terminal cells.

$ go get glonk.dev

Requires Go 1.26 or newer. glonk has no package at its root, so import glonk.dev/engine (and glonk.dev/mesh for 3D) and run go mod tidy once; without it go run stops with a missing go.sum entry.

From a block to a world

Six steps, each a few lines of Go. The pictures are what the engine drew.

1A block

A terminal draws characters in cells, each about twice as tall as it is wide. glonk writes a character and two colors into any cell.

With the upper half block as the character, the two colors are two pixels, one above the other. That is the pixel canvas, and it is the mark at the top of this page.

fb.Set(10, 5, engine.Cell{Character: '@', Foreground: engine.Palette(208)})

canvas := fb.Canvas() // two pixels to a cell
canvas.FillRect(2, 1, 20, 6, engine.Palette(220))
canvas.Compose()

2Sprites

A sprite is a picture at a position: one cell, a frame made from text art, or an animation of frames.

A layer draws its sprites in the order they were added. A space in the art is a hole, so a see-through sprite shows what is behind it.

ship := sprite.FromLines(engine.Cell{Foreground: engine.Palette(208)},
	` /\ `,
	`/__\`,
)
layer := sprite.NewLayer()
layer.Add(&sprite.Sprite{
	Position: geometry.Vector2{X: 2, Y: 1},
	Frame:    ship,
	Overlay:  true, // see-through where the art has a space
})
layer.Draw(fb)

3A level and a camera

A tile map is a level bigger than the screen, written as text art. Solid tiles stop a moving box, so a player slides along a wall.

The camera is a rectangle: the screen, centered on the player and kept inside the level.

level := tilemap.FromLines(map[rune]tilemap.Tile{
	'#': {Cell: engine.Cell{Character: '#'}, Solid: true},
	'.': {Cell: engine.Cell{Character: '.'}},
}, "##########", "#........#", "##########")

moved, _, _ := level.Move(player.Bounds(), geometry.Vector2{X: dx, Y: dy})
player.Position = moved.Min

screen := geometry.NewRect(0, 0, float64(fb.Width()), float64(fb.Height()))
view := screen.CenterOn(player.Bounds().Center()).Within(level.Bounds())

4Solids and light

A mesh is drawn as lines or as shaded faces through a perspective camera, lit by a sun, lamps and ambient light, faceted or smooth.

Cubes, spheres, cylinders and cones come with glonk, and an OBJ file loads with the colors and pictures of its materials.

cube := mesh.Cube(2)
cube.Material.Color = engine.Palette(208)
cam := mesh.Camera{Position: geometry.Vector3{Z: -4}}
sun := mesh.Directional{Direction: geometry.Vector3{X: 0.4, Y: -1, Z: 0.6}}

cube.DrawShaded(fb, cam, mesh.Ambient{Level: 0.2}, sun)

5Both in one frame

3D and 2D share the frame and its depth. Solids are drawn in half-block pixels, a picture stands among them and is hidden where a solid is nearer, and text and widgets go on top.

The recording at the top of this page is this step.

canvas := fb.Canvas()
cube.DrawShadedPixels(canvas, cam, lights...)   // solids, in pixels
tree.DrawScaledDepth(canvas, x, y, w, h, depth) // a picture among them
canvas.Compose()
fb.DrawText(1, 1, "25 fps", engine.Color{}) // and text on top

6Keys, the mouse, and tests

Input is held keys and new presses, key events with their modifiers, typed text, pastes and the mouse.

Update and Draw are plain methods, so a test presses keys with engine.Keyboard and reads the frame as text. Every recording on this page was made that way, with no terminal.

kb := engine.NewKeyboard()
kb.Press('w')
g.Update(1.0/30, kb.Input()) // one frame with W held

fb, _ := engine.NewFrameBuffer(40, 12)
g.Draw(fb)
fmt.Print(fb.String()) // the frame, as text

Start

The smallest program: a box that fills the window, and an @ that walks across it. Esc quits.

package main

import (
	"context"
	"fmt"
	"os"

	"glonk.dev/engine"
)

type game struct{ x float64 }

func (g *game) Update(dt float64, in *engine.Input) error {
	if in.Pressed(engine.KeyEscape) {
		return engine.ErrQuit
	}
	g.x += 20 * dt // cells per second
	return nil
}

func (g *game) Draw(fb *engine.FrameBuffer) {
	fb.DrawBox(0, 0, fb.Width(), fb.Height(), engine.Color{})
	fb.Set(int(g.x)%fb.Width(), fb.Height()/2,
		engine.Cell{Character: '@', Foreground: engine.Palette(208)})
}

func main() {
	err := engine.Run(context.Background(), &game{}, engine.Config{FPS: 30})
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}

Or run an example with nothing cloned:

$ go run glonk.dev/examples/viewer@latest

The same works for cube3d, sprites, world, bounce2d and input.

What is in the box

engine
The loop, the frame of cells, the pixel canvas, drawing helpers, and input from the keyboard and the mouse.
geometry
2D and 3D vectors, and rectangles for boxes, collision and cameras.
mesh
3D meshes as lines or shaded faces, shapes, OBJ loading, lights, and the perspective camera.
sprite
Sprites drawn in layers: a cell, a frame of text art or an animation, with bounds and collision queries.
tilemap
Levels written as text art, drawn through a camera, with solid tiles, routes round walls and lines of sight.
widget
A label, a panel, a bar and a menu, for a HUD or a pause screen.
bitmap
JPEG and PNG pictures, or ones made in code, drawn on the pixel canvas.

Every package is documented, with examples that run, on pkg.go.dev.

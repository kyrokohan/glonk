The glonk manual

Guides to glonk, one for each job, in an order to read them in. Each has code that runs: it is copied from the tests and the examples, which check it.

  • Your first game: install glonk, put a game on screen, and what each part of it does.
  • Keys, text and the mouse: held keys, shortcuts, typing, a paste and the pointer.
  • Testing a game: press keys and read frames with no terminal.
  • Pixels, shapes and pictures: the pixel canvas, shapes, pixel text and pictures.
  • Sprites, collision and tile maps: things that move, walls that stop them, and a level bigger than the screen.
  • Widgets: a label, a panel, a bar, a menu and a text field.
  • A 3D scene: a camera, shapes, lights, wireframes, fog and rays.
  • Models and textures: OBJ files, colors on each vertex, pictures on faces, and see-through faces.
  • A game in a web page: the same game as in the terminal, played in a browser.
  • Terminals, colors and limits: what a terminal needs, what glonk uses where it has more, and what glonk does not do.

Every type and function is documented, with examples that run, on pkg.go.dev. What changed in each release is in the changelog.
